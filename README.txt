GREENLAB WEBSITE — BILINGUAL UPDATE

EDITING
- Open the extracted folder in VS Code.
- Edit index.html for content, style.css for design, script.js for language switching and form behavior.
- Arabic/English text is paired using data-en and data-ar attributes in index.html.
- To change a text, edit both values in the same element.
- The language button switches the page direction (LTR/RTL) and Arabic font automatically.

ADD THE COMPANY LOGO
1. Put the approved logo image in this folder and name it logo.png.
2. In index.html, find: <img id="companyLogo" src="" ...
3. Change src="" to src="logo.png".
4. Keep the logo file inside the same folder before uploading.

PUBLISH / UPDATE WITH NETLIFY
1. Extract Green_Lab_Corporate_Website.zip.
2. Open https://app.netlify.com/drop and sign in.
3. Drag the green_lab_website folder (the folder containing index.html) into Netlify Drop.
4. Netlify creates a public URL.
5. For later updates, edit the files and redeploy the updated folder to the same Netlify site.
6. For official company use, the company should own the Netlify account and connect its domain greenlab-eg.com through Netlify Domain management.
